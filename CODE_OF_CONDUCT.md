# Code of Conduct / 行为准则

## English

Project participation must remain respectful, technical, and constructive. Harassment, discrimination, threats, deliberate disruption, publication of private information, and abusive language are not accepted. Maintainers may edit or remove contributions and restrict participation when necessary to protect the project and its community.

Report conduct concerns privately through the repository Security contact. Reports will be reviewed fairly and confidentially.

## 中文

项目交流应保持尊重、专业和建设性。禁止骚扰、歧视、威胁、故意破坏、公开私人信息及辱骂。为保护项目和社区，维护者可在必要时编辑或移除内容并限制参与。

行为问题请通过仓库 Security 联系方式私下报告，维护者会公平并保密地处理。
